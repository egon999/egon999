- ⚡ **Full-Stack Mastery**: Deeply specialized in **React 19, Next.js 15, Node.js, TypeScript, Python, and Java**, delivering ultra-responsive reactive UIs, sub-millisecond API pipelines, and robust state machines.

- 🛡️ **Systems & Forensic Security**: Developing low-level Windows latency tuners, anti-cheat threat detectors, anti-tunnel forensic inspectors, and NT kernel driver scanners.
